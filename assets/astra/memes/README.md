# Мемы Астры

Короткие ролики-мемы, 1–4 секунды, в форматах mp4, webm или mov. Астра вставляет их, чтобы показать эмоцию, реакцию или иронию. По умолчанию мем идёт без звука, голос автора остаётся главным.

Имя файла — это название, по которому Астра выбирает мем. Называй по смыслу, а не по источнику: `facepalm.mp4`, `shocked-cat.mp4`, `this-is-fine.mp4`, `money-rain.mp4`.

Файлы остаются только на этом компьютере: в публичный репозиторий они не попадают.
