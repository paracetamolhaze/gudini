# Движок Астры

Стиль монтажа «Астра»: Астра (GPT-6 через локальный сервис Codex) пишет монтаж кодом из готовых кубиков, сама смотрит черновик и правит его. Движок — Remotion (React → MP4).

## Устройство

| Папка | Что там |
|---|---|
| `src/kit` | Кубики: камера, субтитры по словам, текст за спиной, заголовок, плашка, панель, карточка, иконка, фото, стрелка, вспышка, звуки. Анимации, шрифты и звуки уже настроены. |
| `src/montage/Montage.tsx` | Проверочный монтаж для Studio. Для каждого ролика его заменяет файл, который пишет Астра. |
| `knowledge/` | Учебник Астры: как монтировать (`director.md`), справочник по кубикам (`kit.md`), образцы монтажа (`examples/`). |
| `director/` | Цикл: задание → монтаж → проверка кода → вырезка автора → черновик → Астра смотрит кадры → финал. |
| `matting/cutout.py` | Вырезка автора из фона (RobustVideoMatting, ONNX, CPU) для текста за спиной. |

## Запуск

```bash
npm ci
npx tsx director/check-examples.ts
npx tsx director/direct.ts --input job/input.json --topic "Тема" --public public --media job --out out/job --sounds ../assets/astra/sounds
```

Для `direct.ts` нужны переменные:
- `CODEX_BRIDGE_TOKEN` (и при необходимости `CODEX_BRIDGE_URL`) — сервис Codex на Windows;
- `ASTRA_PYTHON` — Python с `onnxruntime` и `numpy`;
- `ASTRA_RVM_MODEL` — путь к `rvm_mobilenetv3_fp32.onnx`.

`input.json` — это `AstraInput` из `src/input.ts`: пути к видео внутри `public`, слова на очищенной дорожке, рамка лица.

## Лицензии

- **Remotion** бесплатен для частного лица и компаний до 3 сотрудников. При большем штате нужна платная лицензия.
- **Шрифты** распространяются под лицензией OFL (`public/fonts/OFL.txt`).
- **RobustVideoMatting** — GPL-3.0. Модель работает внутренним инструментом и не распространяется.
- **Звуки и музыка** из Pixabay и Mixkit не хранятся в репозитории: их лицензии разрешают использовать файлы в роликах, но не раздавать их.
