# Гудини 🎩 — ИИ-студия коротких видео

Полный цикл производства вертикальных роликов для TikTok, YouTube Shorts и Instagram Reels:

1. **Сценарий** — пишешь тему, ИИ выдаёт сценарий на ~60 секунд для чтения на камеру.
2. **Съёмка** — встроенный телесуфлёр с записью с веб-камеры, либо загрузка готового файла.
3. **Автомонтаж** — кадрирование в 9:16 (1080×1920), нормализация громкости, крупные «горящие» субтитры по словам (караоке-эффект), генерация описания и хэштегов.
4. **Публикация** — TikTok / YouTube Shorts / Instagram Reels через подключённые аккаунты, либо скачивание готового MP4.

## Запуск

Требуется: Node.js 18+, ffmpeg в PATH (или переменная `FFMPEG_PATH`).

```bash
npm install
npm run dev
```

Сайт: http://localhost:3000

## Режимы работы

Без ключей всё работает в **демо-режиме**: сценарии по шаблону, субтитры по тексту сценария, публикация симулируется. Ключи включают полноценный режим — их можно вписать в «Настройках» на сайте или в `.env` (см. `.env.example`):

| Ключ | Что даёт |
|---|---|
| `ANTHROPIC_API_KEY` | Уникальные сценарии и описания от Claude |
| `OPENAI_API_KEY` | Whisper: субтитры точно по произнесённой речи |
| `GOOGLE_CLIENT_ID/SECRET` | Публикация в YouTube Shorts (YouTube Data API v3) |
| `TIKTOK_CLIENT_KEY/SECRET` | Публикация в TikTok (Content Posting API) |
| `META_APP_ID/SECRET` + `PUBLIC_BASE_URL` | Публикация в Instagram Reels (Graph API, нужен публичный URL сервера) |

Подключение аккаунтов платформ — кнопки «Подключить …» в Настройках (OAuth). Redirect URI для приложений разработчика: `http://localhost:3000/api/auth/<youtube|tiktok|instagram>/callback`.

## Где лежат данные

- `data/db.json` — проекты
- `data/settings.json` — ключи и токены (в git не попадает)
- `data/uploads/<id>/` — исходники и смонтированные видео
