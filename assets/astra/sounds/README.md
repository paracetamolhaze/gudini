# Звуки и музыка Астры

Имя папки — это роль звука. По нему Астра понимает, где звук уместен: она не слышит файлы, а читает роль, название и замеры громкости и темпа.

Формат — mp3, wav или ogg. В каждую папку достаточно 2–3 вариантов, чтобы звук не повторялся из ролика в ролик. Бери звуки, которые тебе самому нравятся на слух. Файлы можно не переименовывать: исходные названия с сайтов тоже подсказывают, что это за звук.

Если раскладывать некогда, кидай всё в `unsorted/` — разберу по названиям.

Где брать бесплатно, для коммерческого использования и без подписи автора: pixabay.com (Sound Effects и Music) и mixkit.co (Sound Effects и Music).

## Звуки: `sfx/`

| Папка | Когда звучит | Что искать |
|---|---|---|
| `whoosh` | вылет текста, смена экрана, разделение экрана | whoosh, swoosh, transition |
| `pop` | появление слова, иконки, эмодзи | pop, bubble pop, ui pop |
| `click` | нажатие в интерфейсе, курсор | mouse click, ui click, tap |
| `typing` | текст печатается | keyboard typing |
| `ding` | галочка, правильный ответ, успех | success, ding, correct |
| `error` | ошибка, «так нельзя», мошенник | error, wrong buzzer, fail |
| `cash` | деньги, монеты, покупка | cash register, coins |
| `notification` | сообщение в телефоне или Telegram | notification, message |
| `riser` | нарастание перед разгадкой | riser, tension build |
| `impact` | удар на главной фразе | cinematic hit, impact, boom |
| `glitch` | сбой, взлом, тревога | glitch |
| `swipe` | перелистывание карточек | swipe, page turn |
| `shutter` | скриншот или фото | camera shutter |
| `tick` | таймер, отсчёт | clock ticking |

## Музыка: `music/`

По 1–3 трека на настроение. Подложка звучит тихо под голосом, поэтому лучше спокойные треки без вокала.

| Папка | Для каких роликов | Что искать |
|---|---|---|
| `calm` | спокойные объяснения | lofi, chill, ambient |
| `curious` | «сейчас объясню», лёгкое любопытство | curious, pizzicato, light corporate |
| `upbeat` | бодрые, позитивные ролики | upbeat, energetic |
| `tense` | истории, мошенники, риски | suspense, tension, dark |
| `dramatic` | разгадка, серьёзные новости | dramatic, cinematic |
| `playful` | смешное, мемы | funny, quirky |
