# Стенд озвучки — Chatterbox Multilingual V3

Локальный синтез речи на видеокарте этого компьютера. Отдельный контейнер, как `clipy`:
сайту на Node не нужны ни torch, ни CUDA. Наружу порт не открыт, вкладка `/test` ходит
сюда через сайт и закрыта тем же паролем.

```bash
docker compose build tts
docker compose up -d tts
```

## Что умеет

Клонирует голос по короткому образцу (10–20 секунд чистой речи) и читает текст на 23 языках,
русский среди них. Подача настраивается двумя ручками:

- `exaggeration` — экспрессия. Выше, чем 0.5, звучит эмоциональнее и быстрее.
- `cfg_weight` — свобода. Ниже, чем 0.5, звучит медленнее и ближе к образцу.

Рекомендации Resemble: обычное чтение 0.5 / 0.5, для хука 0.7 / 0.3, если автор в образце
частит — 0.5 / 0.3, а если образец на другом языке, `cfg_weight` ставят в 0, иначе синтез
подхватит акцент образца.

## Ограничения

- Веса (~3 ГБ) качаются при первой загрузке модели в том `tts-data`, а не в образ.
- Карта одна на весь дом. Пока `clipy` рендерит замену лица, модель надо выгрузить кнопкой
  «Освободить память»: две модели в 8 ГБ 3060 Ti не помещаются.
- Длинный текст режется по фразам и склеивается: за один проход модель дочитывает
  нестабильно, начинаются повторы и обрывы.
- Каждый ответ помечен неслышимым водяным знаком Perth. Так устроен Chatterbox, отключить нельзя.

## API

| Метод | Путь | Зачем |
|---|---|---|
| GET | `/health` | устройство, загружена ли модель, видеопамять |
| POST | `/load`, `/unload` | занять или освободить карту |
| GET POST DELETE | `/voices` | образцы голоса |
| POST | `/speak` | синтез, отдаёт метаданные дубля |
| GET | `/takes`, `/takes/{id}.wav` | сохранённые дубли |
