# Планировщик: постановка всей истории вместо предмета под реплику

Проверка на проекте про Трампа, 13.09.2026. Новых генераций нет, два прогона фазы плана по 0.20 доллара.

## Что изменено в общих инструкциях

Ничего из маршрута «могила → клуб → козы» в подсказке нет. Пример в подсказке взят на постороннем
материале (ремонт велосипеда).

1. **Визуальные задачи всей истории** (`bible.visualTasks`) составляются до раскладки по битам.
   У каждой: что зритель узнаёт, роль (`event`, `illustration`, `explanation`), номера фраз, одно
   выполнимое действие. Повторы по смыслу убираются; объяснение несёт автор, сцены под него нет;
   документы, штампы и решения ведомств не придумываются, если о них не говорит речь.
2. **Убрано требование числа сцен** («нужно не меньше N сцен») и ориентир по доле AI. Осталась
   только верхняя граница по бюджету. Число сцен следует из задач.
3. **Проверка ритма всей последовательности**: авторский кусок короче 2 с между сценами мелькает;
   длинный кусок допустим, если это объяснение из задач; длинный кусок без задачи даёт замечание
   «проверьте, нет ли отдельной задачи», а не гонит за заполнителем.
4. **Разбор плана** ловит сцену без задачи, две сцены с одной задачей, сцену поверх объяснения,
   две задачи с одним пониманием, мелькающий авторский кусок. План без задач получает второй заход.
5. **Обязательное для понимания не всегда обязательно к показу**: событие, чьи реплики планировщик
   сам отдал объяснению, несёт голос автора. Оно не считается потерянным и во второй заход не
   требуется. Раньше требование «покажи каждое» возвращало выдуманный штамп.
6. **Точка входа в клип** (`TimelineSegment.clipIn`): место вставки на таймлайне и начало
   используемого материала независимы. Проверено на перемонтаже с козами: кадры совпадают с
   вариантом через перенос группы.

Совпало с ручным решением без подсказки маршрута: правовые и числовые реплики отданы автору,
документов нет, клуб показан как масштаб места, ферма как факт. Не совпало: соседство пастбища
с полем система не предложила, а фразу про «сотни гектаров дорогой земли» (24.5–29.0 с) не
отнесла ни к задаче, ни к объяснению — отсюда замечание про кусок 22.8–41.2 с. Действие с косой
исчезло: событие описано как состояние «пастбище с козами и скошенным сеном», что честно.

## Замеченные дефекты и что сделано

- Объяснение без поля `learns` выбрасывалось нормализатором, и проверка ритма первого захода не
  видела отданный объяснению отрезок. Исправлено: роль объяснения сохраняет задачу.
- В первом заходе Дональд Трамп сам шёл по аллее в костюме (публичное лицо, разрешено правилом), но
  бит был помечен как видимый Гудини, и проверка костюма сработала как на переодевание. Второй
  заход убрал человека из кадра. Ложная сработка возможна и дальше; правило про публичное лицо и
  флаг видимости персонажа спорят между собой.

## Уточнения после разбора (тот же день, без генераций)

Проверены на сохранённых ответах обоих прогонов и на контрпримерах из других тем: парашют,
посылка, кошелёк, передача ключей.

1. **Обязательность для рассказа и обязательность показа разделены.** Голосу отдаётся только
   исход, который честно не снять: право, статус, сумма, причина. Событие с предметом (разрыв
   купола, вскрытие посылки, подтверждение на экране, ключ в другой руке) остаётся обязательным к
   показу, даже если его реплики помечены объяснением; такой случай даёт отдельное замечание
   «показываемое событие отдано объяснению». Решение берётся из первого ответа, второй заход его не
   меняет. На сохранённых ответах голосу ушёл только отказ в льготе.
2. **Повтор задачи считается по содержанию, а не по идентификатору.** Две сцены одной задачи
   допустимы, если у второй другой решающий момент: общий план и деталь. Повтор — тот же момент с
   другого ракурса.
3. **Под объяснение допустима помогающая иллюстрация.** Голос может называть сумму поверх кадра с
   полем. Запрещено только выдуманное доказательство: документ, штамп, чиновник, цифры. Длинный
   авторский кусок, отданный объяснению, теперь тоже даёт повод для второго захода с вопросом об
   иллюстрации, а не оправдывается меткой автоматически. Обязательного процента AI нет.
4. **Участники и флаг присутствия — одно решение.** Присутствие персонажа следует из того, кто назван
   в кадре: назван персонаж — он в кадре; назван только другой человек — его нет. На сохранённом
   первом ответе сцена «Дональд Трамп идёт по аллее» перестала считаться переодеванием Гудини, и
   этот ответ проходит без запретов.

Следующий платный тест имеет смысл на другой истории: проверить переносимость процедуры, а не
подгонять её под Трампа.
