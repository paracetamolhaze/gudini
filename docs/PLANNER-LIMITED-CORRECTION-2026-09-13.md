# Второй заход как ограниченная корректировка

Прогон такси показал, как второй заход исправляет один недостаток, переписывая верные решения:
развязка вернулась, но подросток стал персонажем канала, камера снова повернулась к пистолету,
объявление о неисправности встало в кадр вопреки справке. Возвращённая развязка этого не
компенсирует, и оба кандидата к генерации непригодны.

## Процедура

1. Второй заход получает первый план целиком (JSON ответа) и замечания.
2. Возвращает только изменения: `beats.replace/add/remove` по паре фраз, `events.update/add/remove`
   и `visualTasks.update/add/remove` по идентификатору, `bible` только при замечании о ролях,
   `related` — связанные изменения с причиной.
3. Область корректировки выводится из замечаний: сцены, события и задачи, которые в них названы;
   сцены, заявляющие события из замечаний; авторские отрезки над фразами событий, которые
   обязаны быть показаны. Под неподтверждённый механизм и опровергнутое утверждение авторский
   отрезок не открывается.
4. Изменение вне области применяется только с объявленной причиной в `related`, иначе
   отбрасывается и попадает в лог.
5. Инварианты: роли и участники меняются только по замечанию о ролях; персонаж не появляется в
   сцене, где его не было в первом плане; статус «подтверждено» не принимается без цитаты; новая
   сцена ложится только на авторский отрезок, соседние сцены не трогаются.
6. После применения весь план собирается и проходит проверки заново; оба кандидата сохраняются,
   выбор — прежним рангом.

## Проверка на сохранённых ответах, без вызова модели

Настоящий второй ответ по такси прочитан как набор изменений к первому и пропущен через область.

| Что делал второй ответ | Итог |
|---|---|
| playedByGudini «подросток», новый список участников | отклонено: замечаний к ролям не было |
| посадка с «Gudini and a second teenager» | отклонено: ставит персонажа в кадр, где его не было |
| сцена с поворотом камеры к пистолету | отклонено: сцена вне области замечаний |
| объявление о неисправности из динамика | отклонено: ставит персонажа в кадр; авторский отрезок под опровергнутое утверждение не открывался |
| ожидание переоформлено в авторский отрезок | применено |
| развязка с полицейским и шариками | отклонено: в кадре Гудини «с руками за спиной» |

После корректировки: 4 сцены, участники прежние, запретов на механизм и роли нет, развязка
по-прежнему не показана, потому что её сцена нарушала инвариант ролей. Исправление должно
найти наблюдаемое раскрытие игрушки без персонажа в кадре.

Синтетический контрпример покрыт тестами: корректировка с подменой ролей, поворотом камеры,
статусом без цитаты, переоформлением ожидания и добавленной развязкой применяет только два
последних, и план после неё проходит без запретов.

## Уточнения к прежним отчётам

- «Полицейский открывает магазин» — постановочная иллюстрация, а не установленная подробность
  задержания; подтверждённым его объявлять нельзя.
- «Проверки стали стабильнее» не доказано: в этом проходе снова исправлялись сами проверки
  (покрытие на формулировках, событие без перехода, восстановление ответа).
