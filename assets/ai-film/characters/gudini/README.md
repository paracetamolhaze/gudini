# Персонаж Gudini — Character Reference Pack

`character.json` — Character Bible: identity персонажа, одежда, узнаваемые детали,
стиль (`styleLock`) и мир (`world`). Claude не переписывает эти поля: он описывает
только роль Gudini в конкретной истории.

## Эталонные картинки

Положите в эту папку до трёх изображений (`png`, `jpg` или `webp`). Они уходят в Veo
как `referenceImages` типа ASSET с каждой сценой, где виден Gudini.

Рекомендуемый набор:

1. `ref-1-full.png` — во весь рост, 3/4 или фронт;
2. `ref-2-face.png` — портрет, лицо крупно;
3. `ref-3-angle.png` — другой ракурс или выражение.

Требования:
- на картинке только персонаж, без надписей, подписей, палитр и рамок (текст с
  референса Veo может перенести в кадр) — из character pack вырежьте отдельные виды;
- вертикальная или квадратная композиция, персонаж целиком в кадре;
- один и тот же стиль рисунка у всех трёх.

Порядок: либо по алфавиту имён файлов, либо явный список в `referenceImages`
внутри `character.json`. Хэш файлов входит в ключ кэша сцен: замена картинки
пересобирает сцены с персонажем, сцены без него остаются в кэше.

Переменные: `AI_FILM_CHARACTER_ID` (по умолчанию `gudini`),
`AI_FILM_CHARACTER_DIR` (по умолчанию `assets/ai-film/characters`).
